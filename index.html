Como criar uma Caixinha Teimosa com Arduino

A clássica Useless Box evoluída com um mecanismo robótico de 2 eixos! Um Arduino Nano coordena dois Micro Servos SG90: a base alinha com a chave ativada (45°, 90° ou 135°) e o braço estende para desativar o interruptor instantaneamente.

Resumo Técnico Duplo Servo SG90
Controlador Principal: Arduino Nano
Atuadores: 2x Servos SG90 (Base + Braço)
Entradas / Interatividade: 3 Chaves Alavancas (S1, S2, S3)
Alimentação Dedicada: Fonte Externa 5V / 2A

Lista de Materiais

Todos os itens utilizados na criação e montagem do projeto MarS.

Microcontrolador

1x Arduino Nano

Unidade central de processamento. Controla os tempos, leituras digitais e sinais de PWM dos servos.

Entradas

3x Chaves Alavanca ON/OFF

Interruptores instalados na parte superior conectados aos pinos digitais D6, D5 e D4.

Placa de Montagem

1x Vector Board

Placa ilhada perfurada usada para soldagem fixa de circuitos e organização dos barramentos.

Atuadores

2x Micro Servos SG90 9g

Servos para a rotação da base (pin D2) e acionamento do braço extensor (pin D3).

Energia Dedicada

1x Fonte de 5V e 2A

Garante alimentação estável e de alta corrente para suportar os picos de consumo dos servo motores.

Controle Geral

1x Chave Liga/Desliga

Chave principal do sistema para ligar ou interromper a energia da fonte de maneira prática.

Conectividade

Fios Diversos (Jumpers / Cobre)

Condutores para ligação entre o Arduino Nano, chaves alavancas, fonte e os conectores dos servos SG90.

Código Fonte C++ (.ino)

Código completo desenvolvido para Arduino Nano com suavização de movimento nos micro servos SG90.

MarS_CaixinhaTeimosa.ino
Arduino C++ 
#include <Servo.h>

Servo servo_base;
Servo servo_braco;

int i;
// Pinos das alavancas (use INPUT_PULLUP para evitar resistores externos)
int pinSwitch1 = 6;
int pinSwitch2 = 5;
int pinSwitch3 = 4;

// Pinos dos servos SG90
int pinServo_base = 2;
int pinServo_braco = 3;

// Posições padrão 
//(sistema desativado)
int posOff_base = 90;
int posOff_braco = 0;

//(Base)
int pos_e2 = 90;
int pos_e1 = 45;
int pos_e3 = 135;

// Variaveis de estado dos switchs
bool e1, e2, e3;

// Posição atual do servo base
int posAtual_base = posOff_base;

// Função de ativação do BRAÇO
void ativar_braco(){
  for(i = posOff_braco; i <= 180; i++){
    servo_braco.write(i);
    delay(5);
  }
  for(i = 180; i >= posOff_braco; i--){
    servo_braco.write(i);
    delay(5);
  }
}

// Função para mover a base
void mover_base(int e, int pos){
  // Verifica se a chave 'E' está ativa (nível lógico LOW devido ao INPUT_PULLUP)
  if(e == LOW){
    // Se posição atual for maior que a posição de destino, diminui até a meta
    if(posAtual_base > pos){
      for(i = posAtual_base; i >= pos; i--){
        servo_base.write(i);
        posAtual_base = i;
        delay(5);
      }
    // Se posição atual for menor que a posição de destino, aumenta até a meta
    } else if(posAtual_base < pos){
       for(i = posAtual_base; i <= pos; i++){
         servo_base.write(i);
         posAtual_base = i;
         delay(5);
       }
    }
  }  
}

void setup() {
  servo_base.attach(pinServo_base);
  servo_braco.attach(pinServo_braco);
  
  pinMode(pinSwitch1, INPUT_PULLUP);
  pinMode(pinSwitch2, INPUT_PULLUP);
  pinMode(pinSwitch3, INPUT_PULLUP);
  
  servo_base.write(posOff_base);
  servo_braco.write(posOff_braco);
}

void loop() {
  // Leitura dos estados dos interruptores
  e1 = digitalRead(pinSwitch1);
  e2 = digitalRead(pinSwitch2);
  e3 = digitalRead(pinSwitch3);
  
  // Verifica qual alavanca foi ligada
  if(e2 == LOW){
    mover_base(e2, pos_e2);
    ativar_braco();
  } else if(e1 == LOW){
    mover_base(e1, pos_e1);
    ativar_braco();
  } else if(e3 == LOW){
    mover_base(e3, pos_e3);
    ativar_braco();
  } else {
    servo_base.write(posOff_base);
  }
}
