Uma caixinha que percebe você e dá tchauzinho.

Sobre a MarS

Este projeto acadêmico explora a integração entre eletrônica, programação embarcada e construção mecânica. O sensor mede a distância; quando detecta alguém próximo, os servos movimentam a base e o braço para realizar dois acenos. O projeto usa uma fonte de 5 V; consulte a documentação do circuito para os cuidados de alimentação e conexão do GND.
